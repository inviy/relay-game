# 유료 기능 1차 — AUTO · 1.5배속 · 연출 스킨 · 상세 통계 (설계)

2026-10-11 · 대상 버전 v3.9.0 · `feature/rarity-weapons`(PR #10) 위에 쌓는다.

## 목적

- 유료로 팔 기능 네 가지를 먼저 만든다. 결제는 아직 붙이지 않고, **마스터(본인)만 무료로 켤 수 있게** 한다.
- 원칙: 돈 내는 기능이 순위에 힘을 주면 안 된다(2026-09-11 메타 진행 안 함, 2026-09-27 광고·순위 충돌).

## 불변 조건

1. **AUTO를 한 번이라도 켠 판은 순위에 올리지 않는다.** `submitScore()`와 `submitBeacon()` 둘 다 막는다.
2. **1.5배속은 순위에 남긴다.** 점수·시계·서버 검사는 게임 시간(`G.t`) 기준이라 서버를 바꾸지 않는다. 반응 시간이 줄어 오히려 어렵다.
3. **스킨은 겉모습만 바꾼다.** 등급 색(`TIERS[*].c`)은 바꾸지 않는다 — 등급 식별이 흐려진다.
4. **서버·DB를 건드리지 않는다.** 모든 저장은 기기 안 `localStorage`.
5. 마스터가 아니면 네 기능 모두 켜지지 않는다.

## 1. 마스터 권한

- `?master=<코드>`로 접속하면 SHA-256을 계산해 소스의 `MASTER_H`와 비교한다. 같으면 `relay:master`에 해시를 저장하고 주소에서 파라미터를 지운다(`history.replaceState`).
- 소스에는 해시만 둔다. 코드 원문은 사용자에게 채팅으로만 전달한다.
- 한계: 코드가 공개된 단일 파일이라 `localStorage`를 직접 고치면 누구나 켤 수 있다. AUTO 판은 순위에 안 오르므로 뚫려도 피해는 「유료 기능 무단 사용」에 그친다. 실제 결제를 붙일 때 서버 검증으로 바꾼다.

## 2. 설정과 화면

- 설정: `relay:paid` = `{auto:0|1, fast:0|1, skin:"base"|"neon"|"plat"}`.
- 메뉴에 한 줄 「유료 기능」 → `#v-paid` 화면: AUTO 토글, 1.5배속 토글, 스킨 3종 선택, 「기록 보기」 버튼. 마스터가 아니면 각 항목에 「🔒 유료 · 준비 중」을 띄우고 누를 수 없다.
- 판 도중: 마스터일 때만 HUD 오른쪽 위(일시정지 아래)에 `AUTO` · `1.5×` 버튼 두 개. 키: `U` = AUTO, `F` = 1.5배속. 이름 칸 등 입력 요소에서는 반응하지 않고, Ctrl·Cmd·Alt 조합은 무시한다.

## 3. AUTO

- **이동**: 사람이 아무 키도 누르지 않을 때만 쓴다(사람 입력이 이긴다). 세 힘의 합으로 방향을 정한다.
  - 회피: 반경 220 안의 적·적 탄환에서 멀어지는 힘(거리 제곱에 반비례)
  - 신호권: 신호권 중심으로 가는 힘(반경 밖이면 강하게)
  - 수집: 반경 400 안 가장 가까운 상자로 가는 힘
- **선택**: `#v-level`이 뜨면 0.6초 뒤 `#picks`의 버튼 하나를 누른다. 우선순위: 진화 카드(`.card.evo`) > 진화 조건을 채우는 카드(`.ev.ok`) > 새 무기·전용 무기 > 무기 강화 > 첫 카드. 진화 갈래·계약·보스 보상은 첫 카드.
- 판 도중 AUTO가 켜진 채로 한 프레임이라도 돌면 `G.autoUsed=true`. 이어하기 저장(`RUNF`)에 남는다.
- 결과 화면: 순위 줄 자리에 「AUTO · 순위 제외」. 개인 기록·도감·연속 기록은 정상.
- 분석: `end` 이벤트에 `auto:true` 추가.

## 4. 1.5배속

- `loop()`에서 프레임 `dt` 상한(.05)을 건 **뒤에** 1.5를 곱한다. hitstop 감속은 그대로 곱해진다.
- 끄고 켜기는 판 도중에도 즉시 반영된다. `end` 이벤트에 `fast:true`(한 번이라도 켰으면) 추가.

## 5. 연출 스킨

- 3종: 기본(`base`) · 네온(`neon`) · 백금(`plat`). 바꾸는 것: 내 탄환 색, 회전 검 색. 개봉 빛기둥은 등급 색으로 차오르는 연출이라 바꾸지 않는다(불변 조건 3).
- 구현: 스킨마다 「원래 색 → 스킨 색」 표를 두고, 탄·검 렌더에서 `skinC(c)`를 거친다. 등급 테두리 빛(shadowColor)은 그대로.

## 6. 상세 통계

- 판이 끝날 때 `relay:hist`에 한 줄 추가, 최근 30판만 유지.
  - `{d:날짜, s:점수, t:초, lv, ch, form, tb:최고 등급, top:[상위 무기 3개 키], a:AUTO 여부, f:배속 여부}`
- `#v-stats` 화면: 최근 판 목록(점수·시간·레벨·기체·AUTO/배속 표시), 내 최고 빌드(최고점 판의 `top`), 무기별 평균 비중(판마다 상위 3개 등장 횟수).

## 하지 않는 것

실제 결제 · 서버 권한 검증 · AUTO 전용 순위표 · 기록 동기화 · 연습 모드 · 후원자 표시(2차).

## 검증

- 마스터가 아니면 `PAID` 토글이 바뀌지 않고, 올바른 코드 해시로만 켜진다.
- 1.5배속: 같은 `loop` 호출에서 `G.t`가 1.5배 흐른다.
- AUTO: 사람 입력 없이 기체가 움직이고, 레벨업 화면이 자동으로 닫히며, AUTO 판은 `submit_score` 요청이 0건이다. 3분 생존은 정보로 기록한다(봇 결과는 느낌을 못 잰다).
- 스킨: 탄 색이 바뀌고 등급 빛 색은 그대로다.
- 통계: 31판째에 가장 오래된 기록이 빠진다.
- 기존 테스트 9개 전부 통과.
