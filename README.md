# RELAY — 중계

브라우저에서 바로 돌아가는 뱀서라이크 로그라이크. 빌드 도구 없이 **단일 HTML 파일** 하나로 동작합니다.

**플레이:** https://relay-signal.vercel.app

---

## 판 하나, 끝은 스스로 온다

모드 선택도 제한 시간도 없습니다. 들어오면 바로 시작하고, **죽거나 종단 재머를 끊으면** 판이 끝납니다.

| | |
|---|---|
| 2분 50초 | 첫 재머 |
| 4기 격파 후 | 종단 재머 — 링 → 나선 → 수렴 3단계 |
| 격파 | 「중계 완료」로 판 종료 (실측 8~9분) |

시간축을 2배로 압축해 돌립니다. 상자·엘리트·구역·재머·적 구성이 `t × 2`로 오고, 점수와 시계는 실제 시간을 씁니다. 그래서 1차 진화 1:03, 2차 1:51, 3차 4:15에 들어옵니다.

**압축은 짧게 죽는 사람에게 특히 좋습니다.** 실제 신규 유저가 3:37에 LV32였는데, 압축이 없으면 같은 시간에 LV18쯤입니다.

위협(적 수·체력)은 1.45배로 **덜** 압축합니다. `pace=2`는 숫자를 압축하지만 사람의 반응속도는 압축하지 못합니다. 둘을 같이 올리면 압축이 순수한 불이익이 됩니다 — 실측으로 이동하는 봇의 생존이 59초까지 떨어졌고, 분리한 뒤 63초로 돌아왔습니다.

### 없앤 것 — 4분/5분 제한 모드

한때 「오늘의 중계 4분」과 「심층 모드」를 나눠 뒀습니다. 실제 피드백에서 **정각에 끊기는 게 생소하고, 모드를 고르라는 것도 생소하다**는 말이 나왔습니다. 그리고 신규 유저 둘은 1:26·3:37에 죽어 제한을 보지도 못했습니다. 얻는 것 없이 어색함만 주는 장치라 걷어냈습니다.

## 오늘의 규칙

시드가 스폰 순서만 바꾸면 "오늘은 다르다"가 체감되지 않습니다. 그래서 매일 규칙이 하나씩 바뀝니다.

| 규칙 | 내용 |
|---|---|
| 밀집 | 적이 1.4배로 몰려온다. 대신 체력이 25% 낮다 |
| 협소 | 신호권이 30% 좁다. 대신 안에서 피해가 25% 더 오른다 |
| 폭우 | 자폭체가 세 배로 쏟아진다 |
| 보급 과잉 | 보급 상자가 1.7배 자주 떨어진다 |
| 강행군 | 모두가 빨라진다 — 나 +25%, 적 +15% |
| 거인 | 엘리트가 1.7배 자주 온다. 상자도 그만큼 |

## 연속 기록

메타 진행은 없습니다. 대신 **연속 며칠 했는지**, **어제 몇 점이었는지**가 메뉴에 뜹니다. 강해지지는 않지만 돌아올 이유는 됩니다. 결과 화면에는 「어제보다 +5,240」이 붙습니다.

## 공유

결과를 복사하면 이렇게 나옵니다.

```
RELAY #20260911 · 오늘의 중계 · 협소
▰▰▱▰▰▱▰▰  신호권 78%
4:00 완주
똥알이 · 방패수 / 기동계 · LV28
41,820점 · 오늘 2위 · 2,225처치
어제보다 +5,240
```

**채운 블록은 그 30초를 신호권 안에서 싸웠다는 뜻입니다.** 이 게임의 실력 축이 그것이라, 막대 하나로 판의 성격이 드러납니다. 점수만 있는 공유물은 안 해본 사람에게 아무 의미가 없습니다.

## 이 게임의 차별점

### 신호권 (Signal Zone)

화면 어딘가에 황금빛 원이 있습니다. 그 안에서 싸우면 **피해 170%**, 밖에서는 100%. 구역은 32초마다 다른 곳으로 옮겨 가므로, 매 32초마다 "지금 자리를 지킬지 옮길지"를 결정해야 합니다. 진화 계열에 따라 이 결정의 무게가 완전히 달라집니다 — 방어계는 구역 안 220% / 밖 85%라 구역에 묶이고, 기동계는 어디서든 135%라 자유롭습니다.

구역 밖에 30초 이상 머무르면 간섭이 발생해 화면에 노이즈가 끼고 적이 빨라집니다.

### 3단계 오퍼레이터 진화

8레벨에 갈래를 고르고, 16레벨과 24레벨에 두 번 더 자랍니다. 갈래에 따라 기체 모양, 전용 무기, 궁극기, 플레이 방식이 전부 달라집니다.

| | 기동계 → 유령 → 특이점 | 방어계 → 요새 → 관제탑 |
|---|---|---|
| 철학 | 신호권에 안 매임 | 신호권을 지킴 |
| 피해 | 어디서든 135% | 안 220% / 밖 85% |
| 1차 (8레벨) | 이동 중 25% 회피 | 6초마다 피격 1회 무효 |
| 2차 (16레벨) | 잔상 분신 2체가 함께 사격 | 자동 포탑 2기 궤도 사격 |
| 3차 (24레벨) | 분신 4체 · 관통 +1 · 피해 +20% | 포탑 4기 · 신호권 +25% · 체력 +80 |
| 전용 무기 | 유도 미사일 | 충격 망치 |
| 궁극기 | 잔상 질주 (3초 무적·이속 2배) | 역송신 (신호권을 내 위치로) |

기체 색과 진화 형태는 **별개 축**입니다. 모양은 진화가, 색은 시작 기체가, 크기는 단계가 정하므로 진화한 뒤에도 어디서 출발했는지가 남습니다.

진화를 거부하는 세 번째 선택지도 있습니다. 레벨업 카드가 4장이 되고 피해 +15%, 24레벨에 피해 ×1.25 · 체력 +60 · 리롤 +2를 받습니다.

### 무기 진화

무기 Lv4 + 특정 패시브 Lv3 → 진화. 레일건, 검풍 폭풍, 뇌우, 지옥불, 궤도 폭격, 지진, 자기 폭풍, 포식 우물, 프리즘 격자. **무기 9종 전부 진화가 있습니다** — 하나만 막다른 길이면 그 무기를 고른 판이 손해가 됩니다.

레벨업 카드에 진화 조건과 달성도가 표시되므로 위키를 뒤질 필요가 없습니다.

### 카드 풀 — 무기 9종 · 패시브 12종 · 슬롯 6칸

한 판에 고를 수 있는 카드 천장이 **65장에서 90장**으로 늘었습니다. 8~9분짜리 판에서 후반 레벨이 10초마다 오는데, 다 찍고 나면 고를 게 남지 않던 자리를 메웁니다.

신규 무기 둘은 기존 다섯과 **다른 결정**을 만듭니다. 기존 다섯은 전부 "닿는 것을 깎는" 무기였습니다.

| 무기 | 하는 일 |
|---|---|
| 중력정 | 우물을 열어 적을 끌어당기고 짓이긴다 — 적을 **어디로 모을지**를 정한다 |
| 굴절 빔 | 바라보는 축으로 관통 레이저를 교차 발사 — **어느 쪽을 볼지**가 딜이 된다 |

신규 패시브 넷은 전부 **조건부**입니다. 기존 여덟이 피해·공속·관통·범위·이속·체력·자석·재생으로 표준 스탯을 이미 다 덮고 있어서, 무조건부를 더 얹으면 "같은 빌드를 더 오래"가 될 뿐입니다.

| 패시브 | 효과 | 조건 |
|---|---|---|
| 치명 회로 | 10%/Lv 확률로 2.2배 | 직접 타격만 (장판·불길 제외) |
| 회수기 | 처치당 체력 +0.1/Lv | 처치 속도에 비례 |
| 반사막 | 맞은 자리가 터진다 (28/Lv) | 맞아야 발동 |
| 과부하 | 피해 +10%/Lv | **신호권 안에서만** |

과부하는 이 게임의 실력 축에 직접 붙습니다. 방어계는 원래 원 안에 묶여 있어 그냥 강화지만, 기동계에게는 "자유롭게 다닐 것인가, 원에 붙어 화력을 받을 것인가"라는 새 결정이 생깁니다.

### 시작 기체 4종

중계사 · 질주자 · 방패수 · 기술자. 시작 무기와 체력·이속이 다릅니다. 진화와는 **다른 축**이라, 어떤 기체로 시작해도 8레벨에 두 갈래 중 하나를 고릅니다.

### 엘리트 특성 5종

장갑(피해 45% 감소) · 광폭(체력 절반 아래에서 1.7배 가속) · 점멸(2.6초마다 순간이동) · 불안정(죽을 때 폭발) · 재생(초당 2% 회복). 링 색과 이름으로 어떤 놈인지 보입니다.

### 끝이 있는 무한 모드

7분에 첫 재머가 오고, 잡아도 끝나지 않습니다. 100초마다 1.55배씩 강해진 재머가 계속 옵니다. 다만 **재머 5기를 끊으면 종단 재머**가 옵니다 — 체력에 따라 링 → 나선 → 수렴으로 패턴이 바뀌는 3단계 보스이고, 격파하면 「중계 완료」로 판이 끝납니다. 약 14분 지점입니다.

끝을 본 뒤에도 **계속 송신**을 누르면 무한 모드가 이어집니다. 끝은 선택지이지 벽이 아닙니다.

### 후반 적 3종

t=260초 이후 구성이 고정되던 문제를 고쳤습니다. 셋은 각각 다른 결정을 강요합니다.

| 적 | 등장 | 강요하는 결정 |
|---|---|---|
| **배회체** | 5분 30초 | 250 거리에서 궤도를 돌며 포위 — 제자리에서 쏘기가 안 통한다 |
| **관측자** | 7분 10초 | 430 거리에서 1.1초 예고 후 예측 사격 — 거리가 안전을 보장하지 않는다 |
| **차폐기** | 9분 | 주변 190 안의 적이 받는 피해 45% 감소, 자기는 못 지킨다 — 처리 순서가 생긴다 |

### 데일리 시드

KST 날짜로 시드를 생성해, 같은 날 접속한 모두가 **같은 신호권 경로 · 같은 적 구성 · 같은 카드 순서 · 같은 규칙**으로 플레이합니다. 운이 아니라 실력으로 순위가 갈리도록.

영구 강화(메타 진행)를 넣지 않는 이유가 이것입니다. 한 번 풀면 "오늘은 모두 같은 조건"이 거짓이 되고, 그러면 이 게임에 남는 게 없습니다.

## 조작

- **이동** WASD · 방향키 · 화면 드래그 (모바일)
- **공격** 자동
- **궁극기** Space 또는 게이지 탭
- **레벨업** 숫자 키 선택 · `R` 다시 뽑기(2회) · `S` 건너뛰기
- **기타** `Esc` 일시정지 · `M` 음소거

## 기술 구조

의존성 없음. 프레임워크 없음. 빌드 단계 없음.

| 영역 | 구현 |
|---|---|
| 렌더링 | Canvas 2D, `shadowBlur` 글로우, 패럴랙스 별 배경 |
| 사운드 | Web Audio API로 실시간 합성 — 효과음과 BGM 모두 (오디오 파일 0개) |
| 폰트 | 서브셋 woff2를 base64로 내장 (외부 폰트 요청 0) |
| 저장 | `localStorage` (프로필 · 연속 기록 · 30일 점수 · 판 이어하기 · 제출 실패 큐) |
| 랭킹·분석 | Supabase REST + PostgreSQL 함수 |
| 배포 | Vercel 정적 호스팅 |

외부로 나가는 요청은 Supabase 하나뿐입니다. 폰트도 이미지도 오디오도 전부 파일 안에 있습니다.

### 판 이어하기

탭을 닫아도 판이 남습니다. 적·탄·파티클은 저장하지 않고 진행 상태(시간·레벨·무기·진화·신호권)만 남겨서, 다시 들어오면 메뉴에 **이어하기**가 뜹니다. 되살린 저장은 즉시 지워지고, **오늘 시드에서만** 유효합니다 — 어제 판은 이어지지 않습니다.

### 랭킹 백엔드

`supabase.sql`을 Supabase SQL Editor에 붙여 넣으면 테이블·검증 함수·뷰·RLS가 한 번에 생성됩니다.

점수는 클라이언트가 아니라 **PostgreSQL 함수가 다시 계산**합니다. 생존 시간 대비 불가능한 처치 수나 레벨은 거부되고, RLS로 테이블 직접 쓰기는 막혀 있어 함수를 통해서만 기록이 들어갑니다. 하루 한 기기당 한 줄이 유지되며 최고점만 갱신되고, 순위표는 최근 30일 롤링입니다.

```
점수 = 처치×6 + 생존초×3 + 레벨×260 + 클리어 12000
```

레벨 비중이 큰 이유는 기록을 분해해 봤기 때문입니다. 예전 공식에서는 점수의 80~90%가 처치였는데 처치 수는 스폰(=시간)에 묶여 있어 잘해도 점수가 거의 안 올랐습니다. 실력이 가장 크게 갈리는 축은 레벨이었습니다.

### 분석

`migration-analytics.sql`로 `events` 테이블과 `track` 함수가 생성됩니다. 순위표에는 끝까지 간 사람만 올라오는 생존 편향이 있어서, 이탈 지점을 보려면 별도 신호가 필요합니다. `land · start · form · end · abandon` 다섯 가지를 남기고, 조회용 뷰(`stat_funnel` · `stat_survival` · `stat_choice`)는 anon 권한이 없어 SQL Editor에서만 보입니다.

### 직접 돌리기

```bash
git clone https://github.com/inviy/relay-game.git
cd relay-game
python3 -m http.server 8000   # 또는 그냥 index.html을 브라우저로 열기
```

랭킹 없이 플레이하려면 `index.html` 상단의 `SB_KEY`를 비워두면 됩니다. 게임은 정상 동작하고 랭킹 영역만 비활성화됩니다.

`SB_KEY`는 Supabase의 anon public 키로, 공개되어도 안전하도록 설계된 값입니다. 실제 권한은 RLS 정책이 통제합니다.

## 앞으로

- 1위의 그림자 — 게임 중에 오늘 1위의 진행 상황을 같이 표시
- 도감 — 발견한 진화 레시피와 적 정보 기록
- 결과 공유를 텍스트에서 이미지로
- 모바일 드래그 조작 실기기 검증
- 적이 플레이어가 아니라 신호권으로 몰려오는 안(案) — "가장 안전한 곳이 가장 붐비는 곳"이 되어 구역 선택이 훨씬 무거워집니다

**메타 진행(영구 강화)은 넣지 않기로 했습니다.** 데일리 시드의 "오늘은 모두가 같은 조건"과 정면으로 충돌하고, 한 번 풀면 순위표가 영구히 오염됩니다. 리텐션 요구의 정직한 부분은 판 이어하기가 대신합니다.
