# RELAY — 중계

브라우저에서 바로 돌아가는 뱀서라이크 로그라이크. 빌드 도구 없이 **단일 HTML 파일** 하나로 동작합니다.

**플레이:** https://relay-signal.vercel.app

---

## 이 게임의 차별점

### 신호권 (Signal Zone)

화면 어딘가에 황금빛 원이 있습니다. 그 안에서 싸우면 **피해 170%**, 밖에서는 100%. 구역은 32초마다 다른 곳으로 옮겨 가고, 적은 플레이어가 아니라 **구역 쪽으로** 몰려옵니다. 가장 안전한 곳이 가장 붐비는 곳이 되는 구조라, 매 32초마다 "버틸지 뚫고 갈지"를 결정해야 합니다.

구역 밖에 30초 이상 머무르면 간섭이 발생해 화면에 노이즈가 끼고 적이 빨라집니다.

### 3단계 오퍼레이터 진화

8레벨에 갈래를 고르고, 16레벨과 24레벨에 두 번 더 자랍니다. 갈래에 따라 기체 모양, 전용 무기, 궁극기, 플레이 방식이 전부 달라집니다.

| | 기동계 → 유령 → 특이점 | 방어계 → 요새 → 관제탑 |
|---|---|---|
| 철학 | 신호권에 안 매임 | 신호권을 지킴 |
| 피해 | 어디서든 135% | 안 220% / 밖 85% |
| 1차 (8레벨) | 이동 중 25% 회피 | 6초마다 피격 1회 무효 |
| 2차 (16레벨) | 잔상 분신 2체가 함께 사격 | 자동 포탑 2기 궤도 사격 |
| 3차 (24레벨) | 분신 4체 · 관통 +1 · 피해 +20% | 포탑 4기 · 신호권 +25% · 체력 +80 |
| 전용 무기 | 유도 미사일 | 충격 망치 |
| 궁극기 | 잔상 질주 (3초 무적·이속 2배) | 역송신 (신호권을 내 위치로) |

기체 색과 진화 형태는 **별개 축**입니다. 모양은 진화가, 색은 시작 기체가, 크기는 단계가 정하므로 진화한 뒤에도 어디서 출발했는지가 남습니다.

진화를 거부하는 세 번째 선택지도 있습니다. 레벨업 카드가 4장이 되고 피해 +15%, 24레벨에 피해 ×1.25 · 체력 +60 · 리롤 +2를 받습니다.

### 무기 진화

무기 Lv4 + 특정 패시브 Lv3 → 진화. 레일건, 검풍 폭풍, 뇌우, 지옥불, 궤도 폭격, 지진.

레벨업 카드에 진화 조건과 달성도가 표시되므로 위키를 뒤질 필요가 없습니다.

### 시작 기체 4종

중계사 · 질주자 · 방패수 · 기술자. 시작 무기와 체력·이속이 다릅니다. 진화와는 **다른 축**이라, 어떤 기체로 시작해도 8레벨에 두 갈래 중 하나를 고릅니다.

### 엘리트 특성 5종

장갑(피해 45% 감소) · 광폭(체력 절반 아래에서 1.7배 가속) · 점멸(2.6초마다 순간이동) · 불안정(죽을 때 폭발) · 재생(초당 2% 회복). 링 색과 이름으로 어떤 놈인지 보입니다.

### 무한 모드

재머를 잡아도 끝나지 않습니다. 100초마다 1.55배씩 강해진 재머가 계속 오고, 끝은 죽음뿐입니다.

### 데일리 시드

KST 날짜로 시드를 생성해, 같은 날 접속한 모두가 **같은 신호권 경로 · 같은 적 구성 · 같은 카드 순서**로 플레이합니다. 운이 아니라 실력으로 순위가 갈리도록.

## 조작

- **이동** WASD · 방향키 · 화면 드래그 (모바일)
- **공격** 자동
- **궁극기** Space 또는 게이지 탭
- **레벨업** 숫자 키 선택 · `R` 리롤(2회) · `S` 스킵
- **기타** `Esc` 일시정지 · `M` 음소거

## 기술 구조

의존성 없음. 프레임워크 없음. 빌드 단계 없음.

| 영역 | 구현 |
|---|---|
| 렌더링 | Canvas 2D, `shadowBlur` 글로우, 패럴랙스 별 배경 |
| 사운드 | Web Audio API로 실시간 합성 — 효과음과 BGM 모두 (오디오 파일 0개) |
| 폰트 | 서브셋 woff2를 base64로 내장 (외부 폰트 요청 0) |
| 저장 | `localStorage` (프로필 · 개인 기록 · 판 이어하기) |
| 랭킹·분석 | Supabase REST + PostgreSQL 함수 |
| 배포 | Vercel 정적 호스팅 |

외부로 나가는 요청은 Supabase 하나뿐입니다. 폰트도 이미지도 오디오도 전부 파일 안에 있습니다.

### 판 이어하기

탭을 닫아도 판이 남습니다. 적·탄·파티클은 저장하지 않고 진행 상태(시간·레벨·무기·진화·신호권)만 남겨서, 다시 들어오면 메뉴에 **이어하기**가 뜹니다. 되살린 저장은 즉시 지워지고, **오늘 시드에서만** 유효합니다 — 어제 판은 이어지지 않습니다.

### 랭킹 백엔드

`supabase.sql`을 Supabase SQL Editor에 붙여 넣으면 테이블·검증 함수·뷰·RLS가 한 번에 생성됩니다.

점수는 클라이언트가 아니라 **PostgreSQL 함수가 다시 계산**합니다. 생존 시간 대비 불가능한 처치 수나 레벨은 거부되고, RLS로 테이블 직접 쓰기는 막혀 있어 함수를 통해서만 기록이 들어갑니다. 하루 한 기기당 한 줄이 유지되며 최고점만 갱신되고, 순위표는 최근 30일 롤링입니다.

```
점수 = 처치×6 + 생존초×3 + 레벨×260 + 클리어 12000
```

레벨 비중이 큰 이유는 기록을 분해해 봤기 때문입니다. 예전 공식에서는 점수의 80~90%가 처치였는데 처치 수는 스폰(=시간)에 묶여 있어 잘해도 점수가 거의 안 올랐습니다. 실력이 가장 크게 갈리는 축은 레벨이었습니다.

### 분석

`migration-analytics.sql`로 `events` 테이블과 `track` 함수가 생성됩니다. 순위표에는 끝까지 간 사람만 올라오는 생존 편향이 있어서, 이탈 지점을 보려면 별도 신호가 필요합니다. `land · start · form · end · abandon` 다섯 가지를 남기고, 조회용 뷰(`stat_funnel` · `stat_survival` · `stat_choice`)는 anon 권한이 없어 SQL Editor에서만 보입니다.

### 직접 돌리기

```bash
git clone https://github.com/inviy/relay-game.git
cd relay-game
python3 -m http.server 8000   # 또는 그냥 index.html을 브라우저로 열기
```

랭킹 없이 플레이하려면 `index.html` 상단의 `SB_KEY`를 비워두면 됩니다. 게임은 정상 동작하고 랭킹 영역만 비활성화됩니다.

`SB_KEY`는 Supabase의 anon public 키로, 공개되어도 안전하도록 설계된 값입니다. 실제 권한은 RLS 정책이 통제합니다.

## 앞으로

- 적 행동 다양화 (지금은 대부분 플레이어를 향해 직진)
- 도감 — 발견한 진화 레시피와 적 정보 기록
- 결과 공유를 텍스트에서 이미지로
- 모바일 드래그 조작 실기기 검증

**메타 진행(영구 강화)은 넣지 않기로 했습니다.** 데일리 시드의 "오늘은 모두가 같은 조건"과 정면으로 충돌하고, 한 번 풀면 순위표가 영구히 오염됩니다. 리텐션 요구의 정직한 부분은 판 이어하기가 대신합니다.
